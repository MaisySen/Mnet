This checkpoint is instrumentation, not a proven root-cause correction, timeout increase, product change, acceptance of the prior failed run or a guarantee of future startup. A later diagnostic-only slice samples the main process wait category and at most32 direct child wait categories only when reporting completed verification or an already-expired command. The sampler reads fixed Linux proc entries with bounded256byte symbol and4096byte child-list limits. It uses an exact fixed allowlist for futex, poll, pipe, sleep and I/O-wait categories; unknown/hidden/disappearing entries remain explicit categories or unavailable counts.
